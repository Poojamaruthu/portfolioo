# Pooja Shri S M — Portfolio

React + Vite portfolio, dark code-editor theme, built from your resume.

## Run locally
```
npm install
npm run dev
```

## Deploy (free, ~2 min)
1. `npm run build` → creates a `dist/` folder
2. Go to https://app.netlify.com/drop and drag the `dist/` folder in
3. You'll get a live URL instantly (you can rename it in Netlify's site settings)

**Alternative — Vercel:**
```
npm i -g vercel
vercel
```
Follow the prompts; it deploys and gives you a live URL.

## Notes
- Update the LinkedIn/GitHub `href="#"` links in `src/App.jsx` (hero-links + project cards) to your real URLs.
- Certification and project "view repo" links are placeholders — swap in your actual links.
